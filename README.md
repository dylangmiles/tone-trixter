# Tone Trixter — build log

The published build log for the Tone Trixter, a guitar pedal that makes a piezo pickup sound like
a studio microphone in real time.

**Live site:** https://dylangmiles.github.io/tone-trixter/

Jekyll site, served by GitHub Pages via `.github/workflows/pages.yml`. Episodes are a
folder-per-episode collection with co-located assets, not the flat `_posts` convention.

Moved here from `pico-tone-trixter/docs/` on 2026-08-13 so the log can span both hardware
platforms. The old path redirects.
